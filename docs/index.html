Features

Everything you need to reverse-engineer any image

🖼️

Hover Button

A subtle button appears when you hover any image. No need to right-click or navigate away.

🗂️

Structured JSON Prompt

Get a rich breakdown covering subject, style, lighting, mood, composition, and camera details.

📋

Copy & Open

Copy the prompt and jump straight to Midjourney, Lovart, CapCut, or Lumina in one click.

🕘

History Panel

Your last 50 analyses are saved locally in a side panel so you can revisit any result.

🔐

Your API Key, Your Data

API keys are stored only in your browser. Images go directly to the AI provider — never through us.

⚡

Multi-Provider

Works with Claude (Anthropic), GPT-4o (OpenAI), and Gemini (Google). Swap providers any time.

How it works

Three steps to any prompt

1

Add your API key

Open the extension settings and paste your Anthropic, OpenAI, or Google API key. It stays in your browser.

2

Hover any image

A 🪄 Retrieve Prompt button appears. Click it — or right-click and choose "Convert to AI Prompt".

3

Copy & create

Your prompt appears instantly. Copy to clipboard or open your favourite image generator directly.
